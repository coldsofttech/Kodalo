# Documentation

Technical documentation for this project lives in this folder. The top-level [README](../README.md) is for users.

- [Architecture](architecture.md): the product design, and how checks, workflows, governance and releases fit together.
- [API](api.md): running the API on its own, settings, endpoints and the OpenAPI contract.
- [User guide](ui-user-guide.md): a screen-by-screen tour of the Kodalo window, with screenshots.
- [UI](ui.md): the Windows window, the React frontend and how it talks to Python.
- [Security](security.md): how requests, secrets, AI calls and posting are protected.
- [Packaging](packaging.md): how the Windows setups are built.
- [CLI reference](cli.md): commands, options, output conventions and exit codes.
- [Repository analysis](repository-analysis.md): how project files, frameworks, tooling and the README are read, and how to add your own configs or ask the AI.
